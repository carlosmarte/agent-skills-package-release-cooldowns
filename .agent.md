# agent-skills-package-release-cooldowns — LLM Entry Reference

A package of 7 Claude Code skills, one per package manager, that document **release-cooldown** (a.k.a. minimum-release-age, quarantine) configuration. The threat model is supply-chain attacks: a malicious package version is usually discovered and yanked within days, so refusing to install anything younger than N days closes the window where a poisoned tarball could land.

Each tool uses a deliberately different config name, file location, and unit — which is the main reason these are seven separate skills rather than one.

## Skills

| Skill | Ecosystem | Config form | Unit | Min version |
| ----- | --------- | ----------- | ---- | ----------- |
| [release-cooldown-npm](./skills/release-cooldown-npm/SKILL.md) | JS | `.npmrc` `min-release-age=7` | days (integer) | npm ≥ 11.10.0 |
| [release-cooldown-npx](./skills/release-cooldown-npx/SKILL.md) | JS | inherits `.npmrc`; inline `--min-release-age=7` | days | bundled w/ npm |
| [release-cooldown-pnpm](./skills/release-cooldown-pnpm/SKILL.md) | JS | `pnpm-workspace.yaml` `minimumReleaseAge: 10080` | minutes | pnpm ≥ 10.16.0 |
| [release-cooldown-uv](./skills/release-cooldown-uv/SKILL.md) | Py | `[tool.uv] exclude-newer = "7 days"` | duration string OR RFC 3339 | uv current |
| [release-cooldown-pip](./skills/release-cooldown-pip/SKILL.md) | Py | `--uploaded-prior-to="..."` CLI only | ISO 8601 timestamp (P7D in ≥26.1) | pip recent |
| [release-cooldown-pipx](./skills/release-cooldown-pipx/SKILL.md) | Py | `--pip-args="--uploaded-prior-to=..."` | inherits pip | pipx current |

## Install

Primary path: the [`vercel-labs/skills`](https://github.com/vercel-labs/skills) installer.

```bash
# All 7 skills, globally, into Claude Code
npx skills add carlosmarte/agent-skills-package-release-cooldowns --all -a claude-code

# Or a single skill, project-local
npx skills add carlosmarte/agent-skills-package-release-cooldowns \
  --skill release-cooldown-pnpm -a claude-code

# Discover without installing
npx skills add carlosmarte/agent-skills-package-release-cooldowns --list
```

Fallback (no `skills` CLI, from a local clone):

```bash
for s in skills/release-cooldown-*; do
  name=$(basename "$s")
  ln -sfn "$(pwd)/$s" "$HOME/.claude/skills/$name"
done
```

Either way, each skill appears as `/<skill-name>` inside Claude Code.

Validation rules:
- `name` ∈ `[a-z0-9-]{1,64}`, no leading/trailing hyphen, no consecutive hyphens.
- `name` equals the folder name.
- No absolute host-specific paths in any file (use `$HOME`, `$(pwd)`, or relative paths).
- Body under 500 lines.
